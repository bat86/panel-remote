# Макеты интерфейса

Это статические макеты 1:1 (1366×728, рабочая область экрана 1366×768), а не скриншот WPF-рендера. Они использовались для проверки композиции, размеров кнопок, переносов длинных подписей и контраста.

- `main-screen.png` — главный экран: панель подключена, включён повтор, звук на панели.
- `diagnostics.png` — окно диагностики с найденной проблемой звука.
- `ui-preview.html` — исходник макета.

Реальное WPF-окно использует те же размеры, цвета, шрифты Segoe UI и структуру сетки; шрифт на Linux-макете отличается, поэтому переносы строк могут немного отличаться.
