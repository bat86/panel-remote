# Проверка на реальной панели

Проверять на Windows 10/11 x64, с реальной интерактивной панелью, подключённой по HDMI (желательно также проверить DisplayPort/USB-C, если школа использует такой кабель).

## 1. Установка без администратора

- [ ] Запустить `PanelRemote.exe` под обычным пользователем (не администратором).
- [ ] UAC не появился.
- [ ] Появился ярлык «Пульт доски» на рабочем столе и в меню «Пуск».
- [ ] В `%LOCALAPPDATA%\Programs\PanelRemote\PanelRemote.exe` есть копия.
- [ ] В `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` есть значение `PanelRemote` с `--tray`.
- [ ] После перезагрузки программа стартует в трее, окно не всплывает.
- [ ] Клик по значку в трее открывает окно.
- [ ] `PanelRemote.exe --portable` не создаёт автозапуск и ярлыки.
- [ ] `PanelRemote.exe --uninstall` удаляет автозапуск и ярлыки.

## 2. Экран

Подключить панель, запустить приложение.

- [ ] В верхней полосе: «ПАНЕЛЬ ПОДКЛЮЧЕНА» и правильное имя панели/разъём.
- [ ] Нажать «ДУБЛИРОВАТЬ НА ПАНЕЛЬ». На панели появляется копия рабочего стола. Одно нажатие.
- [ ] Кнопка «ДУБЛИРОВАТЬ» подсвечена зелёным, внизу «Экран: повтор ✓» и разрешение.
- [ ] Нажать «РАСШИРИТЬ». Появляется второй рабочий стол, статус «Экран: расширен ✓».
- [ ] Нажать «ТОЛЬКО ПАНЕЛЬ». Монитор компьютера гаснет, изображение остаётся на панели.
- [ ] Нажать «ТОЛЬКО КОМПЬЮТЕР». Панель гаснет, компьютер работает.
- [ ] Вернуться в «ДУБЛИРОВАТЬ». Разрешение одинаковое на обоих экранах (проверить в Windows: Параметры → Дисплей).
- [ ] Разрешение повтора поддерживается обоими: нет «No signal» и нет сообщения панели о неподдерживаемом режиме.

## 3. Чёрный экран / handshake

- [ ] При включённом повторе выключить панель кнопкой питания, подождать 5 секунд, включить.
- [ ] Приложение само возвращает изображение (в течение ~10 секунд) или статус остаётся «повтор», а «Диагностика» помогает.
- [ ] Нажать «ДИАГНОСТИКА» при чёрной панели. Программа:
  - [ ] заново применяет режим;
  - [ ] повторяет HDMI handshake;
  - [ ] присылает тестовый звук;
  - [ ] крупно объясняет, что проверить.
- [ ] Нажать «ИСПРАВИТЬ ЗВУК И ЭКРАН» — изображение/звук восстанавливаются, если проблема программная.
- [ ] Если кабель выдернут, диагностика пишет «Кабель не подключён» и «Панель не определена».

## 4. Звук

- [ ] Нажать «ЗВУК НА ПАНЕЛЬ». Звук идёт из динамиков панели, кнопка подсвечена, внизу «Звук: панель ✓».
- [ ] Нажать «ЗВУК НА КОМПЬЮТЕР». Звук возвращается на колонки/наушники компьютера.
- [ ] Проверить, что тестовый звук в диагностике идёт на выбранное устройство.
- [ ] Проверить громкость панели пультом: при нулевой громкости диагностика подсказывает проверить громкость.
- [ ] Перезапустить приложение: последний выбор звука восстановлен.

## 5. Переподключение кабеля

- [ ] Выбрать «ДУБЛИРОВАТЬ» и «ЗВУК НА ПАНЕЛЬ».
- [ ] Выдернуть HDMI.
- [ ] Убедиться, что окно показывает «ПАНЕЛЬ НЕ ПОДКЛЮЧЕНА — ВОТКНИТЕ КАБЕЛЬ HDMI», приложение не падает.
- [ ] Вставить HDMI обратно.
- [ ] В течение ~10 секунд изображение и звук возвращаются сами, без нажатий.
- [ ] Повторить 3 раза.
- [ ] Проверить сценарий «Только компьютер»: после переподключения восстанавливается именно «Только компьютер», а не навязанный повтор.

## 6. Ноутбук и стационарный ПК

- [ ] На ноутбуке «Только компьютер» оставляет встроенный экран, а не внешний монитор.
- [ ] На стационарном ПК с двумя мониторами кнопки «Только компьютер»/«Только панель» выключают именно нужный экран.
- [ ] «Расширить» не оставляет чёрный экран и не включает лишний дисплей.

## 7. Трей и клавиши

- [ ] Кнопка «СВЕРНУТЬ В ТРЕЙ» скрывает окно, иконка остаётся в трее.
- [ ] Клик по иконке открывает окно.
- [ ] Пункт «Поверх всех окон» работает и сохраняется после перезапуска.
- [ ] Пункт «Выход» завершает программу.
- [ ] F8 при открытом окне включает повтор.
- [ ] F9 при открытом окне переключает звук на панель.
- [ ] F8/F9 работают, когда окно свёрнуто в трей (глобальные горячие клавиши).
- [ ] Если F8/F9 заняты другой программой, приложение всё равно работает; в журнале предупреждение.

## 8. Журнал

- [ ] Открыть диагностику → «ОТКРЫТЬ ЖУРНАЛ».
- [ ] В журнале есть:
  - [ ] имя панели, разъём, разрешение, active/available;
  - [ ] выбранные режимы и результаты `SetDisplayConfig`;
  - [ ] аудиоустройства и результаты `SetDefaultEndpoint`;
  - [ ] события подключения/отключения;
  - [ ] полный stack trace при ошибке.
- [ ] Журнал открывается блокнотом без кракозябр (UTF-8).

## 9. Устойчивость

- [ ] Запустить приложение без панели — не падает, показывает инструкцию воткнуть HDMI.
- [ ] Запустить приложение при отключённом звуке/наушниках — не падает, показывает «устройство не выбрано» или компьютер.
- [ ] Свернуть в трей, выключить/включить панель, затем открыть окно — статус актуальный.
- [ ] Перезагрузить Windows при подключённой панели — после входа автозапуск в трее, настройки применились.
- [ ] Проверить на компьютере без интернета и без .NET — приложение работает (self-contained).

## 10. Что приложить к обращению в техподдержку

- журнал `%LOCALAPPDATA%\PanelRemote\logs\panel-ГГГГММДД.log`;
- фото/видео экрана панели и надписи на ней (например, «No signal», «Unsupported format»);
- модель панели и тип кабеля (HDMI/DP/USB-C);
- разрешение и масштаб Windows на компьютере.
