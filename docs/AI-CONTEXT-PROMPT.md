## Контекст
- Приватный репозиторий: https://github.com/bat86/panel-remote
- Ветка: main
- Стек: C# + WPF, .NET 8, net8.0-windows, win-x64, self-contained single-file.
- Назначение: компьютер преподавателя подключён к интерактивной панели. Учитель нажимает одну из 7 огромных кнопок и переключает изображение/звук. Без Win+P, без прав администратора, только русский интерфейс.

4. docs/TECHNICAL.md — как устроены CCD/Core Audio.
5. docs/WINDOWS-START.md — как у меня запускается сборка.

## Если чат не понимает, что за проект

Приложи или вставь:

1. `AGENTS.md`
2. `docs/HANDOFF.md`
3. `docs/TEST-STATUS.md`
4. файл, который правишь (`DisplayService.cs`, `AudioService.cs` и т. д.)
5. лог `%LOCALAPPDATA%\PanelRemote\logs\panel-*.log`
6. скриншот/фото ошибки

Если репозиторий целиком недоступен — можно приложить `artifacts/PanelRemote-source.zip` (он локальный, в git не входит).
